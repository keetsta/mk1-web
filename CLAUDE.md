# фронт keetsta.me/mk1

модуль сайта для визитки mk-1: терминал по Web Serial, прошивка по WebUSB (последний релиз и свой `.uf2`, как у Flipper), try it с шеллом в WebAssembly, подсказки по ОС, если браузер не может, и сноска с командами для своего терминала. плата: `~/Downloads/mk1-card`, шелл и протокол: подмодуль `shell/` (`keetsta/mk1-shell`, его `SPEC.md`), сайт: `keetsta/keetsta-website`. описание и команды: `README.md`.

## правила

- дизайн по правилам сайта (`keetsta-website/CLAUDE.md`): никакого свечения (горящий светодиод — плоский цвет), только иконки react-icons, токены сайта, текст не мельче ~12px, переходы через `--ease`. тексты интерфейса на английском и строчными.
- `src/mk1/shell/core.ts`, `serial/osc.ts`, `flash/uf2.ts`, `flash/picoboot.ts`, `flash/releases.ts` гоняются тестами в Node без сборки (стирание типов): никаких `enum` и свойств-параметров конструктора, импорты между ними с `.ts`.
- `src/mk1/shell/mk1-shell.wasm` собранный и лежит в git: после обновления подмодуля `shell/` — `npm run wasm` и коммит обоих.
- `src/mk1/preview/geometry.ts` и слои лица `src/mk1/preview/layers/f-*.svg` генерируются из платы (`npm run geometry`, нужен kicad-cli из KiCad 9), руками не править. слои лежат в git, чтобы `npm run dev` обходился без KiCad.
- карта на странице: `preview/card3d/` (three.js отдельным чанком, грузится после первой отрисовки). плата и детали лица в миллиметрах по даташитам, поверхность печатается из слоёв платы, свет как у магазина сайта (`popup/engine.ts`). пока движок не готов, без WebGL и для скринридеров остаётся рисунок `CardPreview`. горящий светодиод: плоский цвет поверх тонмаппинга, без bloom и ореола. при reduced motion карта лежит ровно и не двигается.
- в терминале копирование и вставка как в терминале на столе: ctrl+c копирует выделенное (без выделения это прерывание), ctrl+shift+c копирует, ctrl+v и ctrl+shift+v вставляют; на маке cmd, как в браузере.
- кнопка карты нажимается всегда, кроме режима с настоящей картой: тогда считается её собственная.
- порт: фильтр только по vid `0x2e8a`, его проходит любая плата на pico-sdk. разрешённый раньше порт берётся без списка, только если он один; занятый известный порт (первую карту держит другая вкладка, вставлена вторая) ведёт в список кнопкой «pick another port» в панели помощи. карта отличается от чужой платы только hello (нет за 1,5 с, значит «no answer» и та же кнопка). переподключение после прошивки открывает порт из события `connect`, а не первый из `getPorts()`.
- прошивка без кнопки на карте: страница отправляет карту в загрузчик (1200 бод) через открытый терминал, а с закрытым через разрешённый раньше порт. такой порт сначала открывается ради hello и только потом получает 1200 бод: фильтр пропускает любую плату на pico-sdk, и 1200 бод отправили бы чужую плату в загрузчик под прошивку карты. сам загрузчик (WebUSB, «RP2350 Boot») браузер спрашивает один раз: у RP2350 в BOOTSEL есть серийный номер, и разрешение остаётся.
- плашка о новой прошивке (`flash/Update.tsx`): релиз спрашивается один раз при открытии страницы (`useLatest`), плашка только после hello карты, когда релиз новее (`isNewer`: обе версии `x.y.z`, иначе `compareVersions` назвал бы новее что угодно). при открытой панели прошивки её нет. «update» открывает панель с фокусом на install и сам не шьёт: запись запускает только кнопка в панели.
- где браузер до карты не достаёт никогда (айфон, Safari, Firefox до 151), первой кнопкой стоит try it. Firefox 151+ умеет Web Serial без WebUSB: прошивка там через диск `RP2350`, но карту, которую видит, в загрузчик страница отправляет сама.
- анимации через `motion` (как на сайте): появление блоков, раскрытие панелей, смена статуса. общие куски в `anim.tsx`: `Unfold` (панель раскрывается вместе со своим gap), `Smooth` (высота плавно идёт за содержимым), `Swap` (иконка сменяет иконку). карта на курсор не реагирует и сама не вращается: приподнимается над страницей при появлении и дальше лежит в покое. при нажатии плата не шевелится: толкатель кнопки уходит на свой ход 0,2 мм и темнеет (ход спереди не виден), как в плоском рисунке.
- терминал виден, только когда есть с кем говорить (карта или try it): свёрнутый он остаётся смонтированным и `inert`, чтобы не терять то, что карта или шелл написали до раскрытия. сноска про свой терминал (`TerminalNote`) одной строкой, переносится только между системами; видна всегда, кроме открытой панели помощи, где то же подробнее. на телефоне без Web Serial она отправляет на компьютер, а не в chrome: на iPhone любой браузер внутри Safari и до usb не достаёт.
- `.mk1` это flex-колонка, а не grid: свёрнутый блок отдаёт gap отрицательным margin, а трек грида меньше нуля не бывает.
- звука нет: пищалки нет ни на карте, ни в шелле, и кадры протокола несут только матрицу.
- после изменений: `npm run build` (tsc strict) и `npm test` без ошибок, вид проверять `tools/shot.mjs` (системный Chrome со SwiftShader для WebGL, светлая и тёмная тема, iPhone, браузер без Web Serial и WebUSB, Firefox 151+, порт, который не здоровается, вторая карта при занятой первой и карта на старой прошивке с плашкой и установкой на поддельном загрузчике WebUSB; вторым аргументом `card` снимает только карту, `nousb`, `firefox`, `silent`, `busy` или `update` только этот случай (`update` ещё узко, с reduced motion и с закрытым терминалом); `SHOT_URL` для dev-сервера).
